    Setup guide ↗

    1. Connect the GitHub App

      Run setup and install the App on your personal account.

    2. Run the first workflow

      In a private repository, run runquill workflow init. Commit the workflow and select Run workflow on GitHub.

      Runquill discovered the first-job workflow.

    3. Confirm cleanup

      When the job finishes, Runquill removes its runner. Check the job result on GitHub.
